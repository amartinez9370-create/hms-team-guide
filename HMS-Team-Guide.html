Switch your module to the database

This is your module's main work

Keep your forms exactly as they are. Change only the code that loads and saves data. Your old lists, text files or other databases are no longer needed.

  1. Find where your module loads its data. Replace it with the Show data in a grid example.
  2. Find where your module saves data. Replace it with the Save a new record example.
  3. Check the table "Who writes what" near the end of this page to find your tables.
When the database refuses something, it explains why in plain words, for example "That time slot is already booked." This is the database doing its job. Db.Friendly(ex) shows that message to the user.

Show data in a grid

dataGridView1.DataSource = Db.Query(
    "SELECT PatientCode, FullName, PhoneNumber, Age FROM vw_patients ORDER BY LastName");

Save a new record

// at the top of the file:  using HMS.Data;  using MySqlConnector;
try
{
    using var conn = Db.Open();
    using var tx = conn.BeginTransaction();

    string code = Codes.Patient(conn, tx);      // makes PAT-20261010-001; never type codes

    using var cmd = new MySqlCommand(@"
        INSERT INTO patients (PatientCode, FirstName, LastName, DateOfBirth, Gender, PhoneNumber)
        VALUES (@code, @first, @last, @dob, @gender, @phone)", conn, tx);
    cmd.Parameters.AddWithValue("@code",   code);
    cmd.Parameters.AddWithValue("@first",  txtFirst.Text);
    cmd.Parameters.AddWithValue("@last",   txtLast.Text);
    cmd.Parameters.AddWithValue("@dob",    dtpDob.Value.Date);
    cmd.Parameters.AddWithValue("@gender", cboGender.Text);
    cmd.Parameters.AddWithValue("@phone",  txtPhone.Text);
    cmd.ExecuteNonQuery();

    tx.Commit();                                 // nothing is saved until this line
    MessageBox.Show($"Saved. Patient Code: {code}");
}
catch (MySqlException ex)
{
    MessageBox.Show(Db.Friendly(ex));            // a plain-English reason
}

Five rules for everyone

Never type a code

Get codes like PAT-, APT- and BILL- from Codes.Patient(…) and the others. Then two people can never make the same code.

Spell statuses exactly

Booked, Completed, Cancelled, No-show. The database refuses other spellings, like "No Show".

Use @parameters

Pass values with cmd.Parameters. Never paste text from a text box straight into the SQL.

Show the friendly message

Catch MySqlException and show Db.Friendly(ex). The user gets a clear reason.

Ask before changing tables

Need a new column? Ask the schema owner. Never change tables yourself in phpMyAdmin.

The database does these for you

Do not write code for these. They already happen.

  • Booking an appointment gives it the next token number.
  • Saving a consultation marks the appointment Completed.
  • Dispensing medicine and stock adjustments change the stock, oldest expiry date first.
  • Saving a lab result sets Abnormal and marks the order Completed.
  • Finalizing a bill gives it its BILL code.
  • Age, stock totals, bill totals and payment status are calculated in the views (names start with vw_).

If something goes wrong

MySQL will not start in XAMPP

Another program is using port 3306. Close other database programs and click Start again. Still stuck: restart the computer.

"Unable to connect to any of the specified MySQL hosts"

MySQL is not running. Start it in XAMPP (step 2).

"Unknown database 'hospitalms'"

Import schema.sql, then seed.sql (steps 4 and 5).

"Access denied for user 'root'"

Your XAMPP has a database password. Ask the team lead to set it in Db.ConnectionString.

"The type or namespace 'MySqlConnection' could not be found"

Add the reference to HMS.Data (step 7, part 4), and add using MySqlConnector; at the top of the file.

My module's name says "(not added yet)"

The folder and the Assembly name must both be exactly HMS.ModuleNN, and HmsModule.cs must be in your project. Then rebuild (step 7 and step 8).

A message like "That time slot is already booked"

That is not a bug. A rule stopped a mistake. Show the message to the user.

The data looks wrong or messy

Start over: import schema.sql, then seed.sql.
